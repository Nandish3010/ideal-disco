# Submission deck

Marp Markdown. Slides are in `slides.md`; items in `[brackets]` are placeholders to fill from cited sources before export.

Export to PDF:

```
npx @marp-team/marp-cli deck/slides.md --pdf
```

Live preview: `npx @marp-team/marp-cli -s deck/`. Speaker notes are HTML comments and are not rendered in the PDF.
